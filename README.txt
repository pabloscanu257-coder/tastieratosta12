COME CREARE L'APK
1. Installa Android Studio sul PC.
2. Apri Android Studio.
3. Scegli "Open" e seleziona la cartella TastieraSostituzione.
4. Aspetta che Gradle finisca la sincronizzazione.
5. Vai su Build > Build Bundle(s) / APK(s) > Build APK(s).
6. L'APK verrà creato nella cartella:
   app/build/outputs/apk/debug/

COME INSTALLARLO SUL LENOVO
1. Copia l'APK nel tablet (USB, Drive, email, ecc.).
2. Apri il file APK sul tablet.
3. Se Android lo chiede, autorizza l'installazione da quella sorgente.
4. Apri l'app "Tastiera Sostituzione".
5. Premi "Apri impostazioni tastiere".
6. Attiva "Tastiera Sostituzione".
7. In un campo di testo apri il selettore della tastiera e scegli "Tastiera Sostituzione".

NOTA PRIVACY
La tastiera di questo progetto non contiene internet, account o raccolta dati.
Scrive semplicemente il carattere trasformato nell'app che sta ricevendo il testo.
